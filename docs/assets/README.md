# 素材与许可证清单

当前仓库不包含生产背景图片、字体、模板或外部数据集。

滑块生成器测试使用测试代码实时生成的色彩渐变图，权利归本项目贡献者并随仓库按 Apache-2.0 许可；Widget fixture 同样只使用本地程序生成的 PNG。它们仅用于确定性测试，不构成生产素材池。
