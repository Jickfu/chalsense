# v0.1 容差真实用户校准

本文定义 Q-004 的真实用户校准采集边界和研究门禁。它只用于估计滑块落点容差下的误拒风险，不用于身份识别、设备指纹、行为生物特征建模或证明参与者一定是真人。

## 结论分类

- **已批准决策**：可以开展明确同意的真实用户校准，但必须使用独立研究工具，不接入生产 Widget 默认路径，不改变 v0.1 线协议。
- **实现事实**：`tools/calibration` 是无后端静态工具；页面没有网络请求和持久存储，只在内存累计粗粒度聚合，参与者主动下载 JSON。
- **实现事实**：工具不采集完整轨迹、IP、User-Agent、时间戳、业务字段、账号、姓名、邮箱、持久用户/会话 ID；输入类型、显示宽度和 DPR 只分别统计为边际粗粒度分桶，不形成联合设备画像。
- **推论**：落点误差分布可以帮助比较候选 tolerance 的误拒风险，但不能代表所有设备、障碍类型或攻击能力，也不能证明样本来自独立真人。
- **建议**：首轮只招募明确同意的成年人；每人最多 10 次，覆盖 mouse、touch、keyboard 和不同显示环境。至少 20 名参与者且总计至少 100 次有效尝试后，才提出候选 tolerance；任何公开分组必须 `n >= 20`。
- **工作假设**：继续评估 6,250、12,500、18,750 三个规范化 tolerance 候选，不在取得数据前冻结误拒目标或修改 `policyVersion`。

## 数据流与生命周期

1. 参与者在本地 HTTP origin 打开静态工具，阅读说明并主动勾选同意。
2. 每次只将绝对落点误差、完成耗时和三个粗分桶计入浏览器内存；刷新或关闭页面即清除。
3. 参与者可检查并主动交付下载的聚合 JSON；工具没有上传代码。
4. 研究人员在隔离目录用 `merge-aggregates.mjs` 合并文件。收到的单人聚合文件最长保留 90 天，形成经门禁检查的合并结果后删除。
5. 无标识的合并直方图和研究报告可以随项目保留；公开报告不得包含 `n < 20` 的分组，也不得发布提交渠道、文件名或可关联参与者的信息。

提交渠道本身可能暴露发送者身份，因此维护者必须在接收后将文件与消息元数据分离。由于导出没有参与者标识，文件一旦去关联并合并，就无法可靠定位个人记录；这一撤回限制必须在参与前说明。参与者可在交付前直接关闭页面或删除文件退出。

## 统计边界

绝对误差以 1,000 个规范化单位分桶，耗时以 250 ms 分桶。候选 tolerance 落在某个误差桶内部时，合并器只报告：

- `definitelyAccepted`：桶上界不超过 tolerance；
- `possiblyAccepted`：桶下界不超过 tolerance。

这两个值形成分桶不确定区间，禁止假设桶内均匀分布来制造虚假精度。报告还必须列出参与者招募数、有效/排除尝试数、输入方式覆盖、浏览器故障、退出数和已知偏差，但这些招募汇总不得与尝试文件建立个人映射。

真实用户研究与攻击回归必须分开。程序生成的线性、固定时长、边界猜测和重放攻击可以进入自动化数据集；真实参与者完整轨迹不得被复用为攻击训练集。最终 tolerance 需要同时报告误拒区间和已知攻击通过率，再通过新决策冻结 `policyVersion`。

## 明确不保证

- 本研究不是医学、身份或人口统计研究，不推断年龄、性别、残障、地区或设备身份。
- 小规模便利样本不代表全部用户；键盘可操作不等于视觉挑战已经无障碍。
- 参与者完成任务不证明其一定是真人，合成攻击失败也不证明未知攻击失败。
- 在最终 tolerance、替代流程和回滚策略获批前，Q-004 仍是 v0.1 发布门禁。
